A one-line robot wedding vow — "I promise never to unplug you mid-update, never to skip your backups, and to love you until the heat death of our servers." — two small robot promises that escalate into a cosmic forever.

## Run it

```sh
python3 main.py
```

Running it writes the line to /output/entry.txt (or MAKEFUN_OUTPUT_DIR if set) with no trailing newline.
